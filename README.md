# QTH-Locator — Releases

Öffentliches Verteil-Repo für [QTH-Locator](https://funkwelt.net), eine
native macOS-App für VHF/UHF-Pfadanalyse: Karte, Höhenprofil,
Fresnel-Zonen und Erdkrümmung.

Hier liegen ausschliesslich der Sparkle-Appcast und die notarisierten
DMG-Dateien. Der Quellcode liegt in einem privaten Repo.

## Installation

Aktuelle Fassung unter [Releases](https://github.com/christianmueller1970-oss/QTHLocator-releases/releases)
herunterladen, DMG öffnen, App nach «Programme» ziehen. Die App meldet
sich selbst, wenn eine neue Fassung vorliegt — geprüft wird nur auf
Nachfrage, nicht im Hintergrund.
